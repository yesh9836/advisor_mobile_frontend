# lead-management-production

Lead management platform for financial advisors with subscription-based access.

## Features

- Role-based authentication (Advisors & Admins)
- Stripe subscription management
- Lead distribution by state licenses
- License verification system
- Audit logging

## Tech Stack

### Backend

- FastAPI (Python 3.11+)
- SQLAlchemy + MySQL
- Stripe for payments
- JWT authentication

### Frontend

- React 18 + TypeScript
- Vite
- React Query for data fetching
- Stripe Elements for payments
